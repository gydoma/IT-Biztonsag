```sh
useradd user160184
su user160184
ssh-keygen
ssh-copy-id root@localhost
------------------------------------------------------------------
useradd -m user160184
su - user160184 -c "ssh-keygen -t rsa -N '' -f ~/.ssh/id_rsa"

cat /home/user160184/.ssh/id_rsa.pub >> /root/.ssh/authorized_keys
```

## 3. Who signed the file /root/contract-86302.txt, Anne, Bob, Carol, Daniel or Eve? The signature was created with the help of the SHA256 hash algorithm and stored in the file: /root/contract-86302.sha256.signature.

The public key of {name} is in /root/{name}-86302.pub.pem.

Write the answer (the name) to to the file: /root/86302.ans.

```sh
openssl dgst -sha256 -verify /root/{name}-86302.pub.pem -signature /root/contract-86302.sha256.signature /root/contract-86302.txt
echo {name} > /root/86302.ans
```

## 4. Download the file 5d3a8e1b with the help of the command below.

```sh
curl -o /5d3a8e1b https://progcont.hu/docs/IT-Security/loop/5d3a8e1b
```

The file contains an encrypted filesystem in LUKS format. The password is: 5d3a8e1b. Copy the content of the filesystem to the directory: /root.

```sh
losetup -f /5d3a8e1b
cryptsetup luksOpen /dev/loop0 loop
INPUT: 5d3a8e1b passphrase
mount /dev/mapper/loop /mnt
ls /mnt
cp -r /mnt/070f /root/
```

## 10. Create a new crypto_LUKS encrypted xfs filesystem on /dev/sdc and mount it to the /mnt directory.

```sh

cryptsetup luksOpen /dev/sdc x
mkfs.xfs /dev/mapper/x
umount /mnt
mount /dev/mapper/x /mnt
```
